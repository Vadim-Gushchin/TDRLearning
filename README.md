
Project Overview

This is a learning project. I started by copying an existing Unity game and then iteratively modified its code and gameplay behavior of various game objects.
Reference https://www.youtube.com/@TinyGamesUnity
Low chance to update this. May be if  TinyGames will complite his course. 


What I Learned / Implemented
Unity Fundamentals: MonoBehaviour, GameObject and Transform,  Animator(and Bland tree), Colliders and Rigidbody
Gameplay Systems: Coroutines (basic usage for timed/asynchronous logic),State machine (basic implementation and usage),Camera(Cinemachine) & AI Navigation(NavMesh)
C# Concepts: Events: how to create them and safely subscribe/unsubscribe; Singleton pattern: how to implement and use it; Delegates and properties in gameplay logic

Summary : Overall, this project helped me consolidate core Unity systems and strengthen my understanding of reusable gameplay code patterns and C# language features.
